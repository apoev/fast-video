# Fast Video

Управление скоростью онлайн-видео в Chrome и в Safari на iPhone и iPad. Поведение повторяет Dynamo 2.3 для Safari на Mac: те же действия, шаг 0.1 и диапазон от 0.1× до 9.9×.

Код написан заново. Значки Dynamo, их обфусцированный скрипт и отчёты на сервер разработчика сюда не входят. Настройки хранятся только на устройстве.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| S | Медленнее на 0.1× |
| D | Если скорость не 1×, вернуть 1×. Если уже 1×, поставить свою скорость |
| F | Быстрее на 0.1× |
| E | Перемотать текущий ролик к концу. Если на экране уже есть кнопка пропуска рекламы, нажать её |
| В поле ввода | Клавиши не перехватываются |

Свою скорость и сами клавиши можно поменять. На сайте, где буквы мешают, выключите Fast Video только для этого домена.

Скорость ставится на HTML5-видео, в том числе внутри фрейма. Поверх видимого ролика на секунду появляется цифра. Если сайт тут же возвращает свою скорость, значение ставится снова.

## Chrome

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. На странице с видео нажмите S, D, F или E. Иконка Fast Video открывает скорость, список сайтов-исключений и клавиши.

Кнопки поверх ролика на компьютере выключены. Их можно включить в окне расширения. На тач-экране они появляются сами, когда на странице есть видео.

## iPhone и iPad

Нужен менеджер userscript: [Userscripts](https://apps.apple.com/app/userscripts/id1463298887) или Tampermonkey. Расширение включается в Настройки → Safari → Расширения.

Откройте в Safari файл скрипта и подтвердите установку:

https://github.com/apoev/fast-video/raw/main/userscript/fast-video.user.js

На странице с видео внизу экрана появляются кнопки −, текущая скорость, + , пропуск и настройки. С аппаратной клавиатурой работают S, D, F и E. Настройки общие для сайтов, если менеджер поддерживает `GM_setValue`.

Полноэкранный системный плеер iOS рисуется отдельно от страницы: кнопки скрипта в этот слой не попадают, а скорость там может игнорироваться. Управляйте роликом, пока он встроен в страницу.

## Проверка

```bash
node test/engine.test.js

```
